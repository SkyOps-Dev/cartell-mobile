# Open Parity Issues

Differences seen between the React Native app and the Flutter app that are **not fixed yet**.
Unlike the quirk register (`spec/19-quirks-register.md`), which lists Flutter behaviour to copy,
this lists places where the RN copy does not yet match Flutter. Each row is fixed before final
acceptance (PORTING_PLAN Phase 19), or moved to the quirk register with client approval.

How to compare: install both apps on one phone ("Cartell" = Flutter, "Cartell RN" = RN), open
the same screen in each, and take screenshots at the same text size and orientation.
